#Expense-Tracker#

This is my web project of calculating expenses overall of a month
This is project is made up of using html , css , javascript
This project use various outer sources and free sources for smaller codes 
This project has a web app system with light mode and dark mode switchable options
This project has three section or pages :-
First section goes for data entry of credit , debit with a short note of where it come from or go through 
Second section goes for overall view of credit , debit and a smart pie chart which differentiate where the money goes
Third section goes for the database where every month calculation was stored in the short form for a whole year 
This is my overall project of expense tracker with a minimum & simple UI
